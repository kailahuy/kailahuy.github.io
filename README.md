# Dreams Public Web Hosting

This repository contains only tested Web release artifacts under `site/` and the GitHub Pages deployment workflow. The application source remains private and separate.

The hosting project is prepared, but the application is not published until its public API is ready, the artifact is built for that API, and acceptance tests pass. An empty repository is not a running Dreams product.

Expected site origin after a verified release: `https://kailahuy.github.io`.

Do not commit environment files, provider credentials, account data, test reports or source maps here.
